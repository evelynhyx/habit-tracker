// Habit Tracker \\

Want to start a habit? Use this cute and cozy habit tracker to make sure you never miss a day! Monkey's like the mascot of the website for a little extra cuteness and inspiration 🫶
Remember: Consistency is key - You can do it!

------
I made this project because it's a website that uses HTML and CSS (something I'm familiar with); however, I was never really good at javascript. I know this project uses a lot of JS, so this is the perfect opportunity to learn it!

------
Habit Tracker involves the use of some HTML, CSS, and a lot of JS. I structured it so that javascript can be easily implemented into the HTML and CSS code. Honestly, I'm very indecisive and I don't stick to what I originally think about. I decided in the middle of the website's development that it should be monkey themed instead of cozy teddy bear (?) themed. Because of this, I've done quite a bit of CSS too. I also added a lot of cool animations and I'm especially proud of my modal.

------
The main challenge I came across was javascript as it's relatively new to me. I encountered lots of errors and later on, I realized that most of it was just formatting errors, so I spent some time getting familiar with javascript's format. I also spent a LOT of time figuring out for loops because they're honestly really confusing. I had to watch a few videos and get some people to teach it to me 🥹 I still don't get it that well, but I do feel like I'm getting better! Also, I really want to get familiar with modals because I feel like I'll be using it a LOT in the future since I've already used it twice now.
